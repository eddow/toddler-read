Toddler Reader

Privacy

Nothing is transmitted to Toddler Read servers. This app scans QR codes and plays the audio or text that the code contains. Network access is only used when a scanned QR code points to an online audio URL.

Reading Voices

Text cards use the device text-to-speech voices. Configure the voices and languages before reading multilingual cards.

  • On Android, open Settings, then Accessibility, then Text-to-speech output.
  • On iPhone, open Settings, then Accessibility, then Spoken Content, then Voices.
  • Install the languages you need and test the selected voice.

Keep It Handy

The reader works as a web app on iPhone and Android. Add it to the home screen for a full-screen launcher.

  • On iPhone, open this reader in Safari, tap Share, then Add to Home Screen.
  • On Android, open the browser menu, then Install app or Add to Home screen.
  • Enable app pinning in Android Settings, usually under Security or Privacy.
