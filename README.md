# Toddler Audio Player

A single‑page, tap‑friendly audio player for 1+ year olds.

Allows you to transform a mini-smartphone to an QR-codes-audio-book reader.

## How to use: browser

Host by yourself or browse `https://toddler-read.netlify.app`

## How to use: Android

`reader` has been built in `tr.apk` - just copy/install it on android
